# RAG-Powered Chat App on the Vienna Conventions of 1961, 1963, and 1969

This is an implementation of a Retrieval-Augmented Generation chat app where you can ask questions about the Vienna Conventions of 1961, 193, and 1969. These conventions are on Diplomatic Relations, Consular Relations, and on Law of Treaties, respectively. This app uses Google Gemini 2.0 Flash as its base LLM, MongoDB Atlas as its vector database, and is housed on Streamlit. You may access the app here: https://vienna-conventions-chat-application.streamlit.app/
